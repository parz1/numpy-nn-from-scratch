## 目前讨论到的理解

Tokenizer 将文本编码为 token ID 序列，也可以将序列解码回文本。它可以独立于神经网络实现；基础版本用纯 Python 即可，不需要 GPU 或反向传播。

BPE 的训练主要是统计和合并。Byte-level BPE 从 UTF-8 字节开始，以 256 个字节值作为基础词表，反复合并频繁相邻的 token 对。编码时需要使用训练得到的合并规则和顺序。

BPE 并不天然排斥中日文。语料的语言比例、词表大小和分配，以及是否从字节开始，都会影响编码效率。常用汉字和假名通常占 3 个 UTF-8 字节，但不一定占 3 个 token。

## 可以尝试的小实验

1. 写字符级 tokenizer，实现 `encode` 和 `decode`，考虑没见过的字符如何处理。
2. 写 byte-level BPE，观察每一步选择了哪一对、合并后序列怎样变化。
3. 检查中英文、日文、空格、换行和 emoji 能否编码后完整还原。
4. 固定词表大小，改变训练语料的语言比例，比较同一组中英日文本的 token 数。比较时同时记录语料和词表设置。
