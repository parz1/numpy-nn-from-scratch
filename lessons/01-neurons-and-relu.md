# 第 1 课：用神经元表示温度不适程度

对应代码：[lesson01_temperature.py](../exercise/lesson01_temperature.py)。

## 本课的问题

假设 18℃ 到 26℃ 是舒适区，超出后，偏离几度就有几分不适。怎样用几个简单计算表示这个规则？

目标函数是：

$$
y = \max(0, x - 26) + \max(0, 18 - x)
$$

这是人为规定的教学例子，不是对真实人体舒适度的测量。

## 神经元计算什么

先对输入做加权和偏移：

$$
z = wx + b
$$

再通过 ReLU：

$$
\operatorname{ReLU}(z) = \max(0, z)
$$

`w` 控制斜率和方向，`b` 移动开启位置。当 `w` 不为零时，`wx+b=0` 的位置是 `-b/w`。

代码用了两个神经元：

```python
h1 = relu(1 * x - 26)    # 超过 26℃ 才开启
h2 = relu(-1 * x + 18)   # 低于 18℃ 才开启
y_hat = h1 + h2
```

| 温度 x | 太热 h1 | 太冷 h2 | 总不适程度 |
| --- | --- | --- | --- |
| 14 | 0 | 4 | 4 |
| 22 | 0 | 0 | 0 |
| 30 | 4 | 0 | 4 |

## 数组形状

`np.arange(10, 35, 4)` 生成 `[10, 14, 18, 22, 26, 30, 34]`，形状是 `(7,)`。标量参数作用在每个温度上，`h1`、`h2` 和 `y_hat` 也都是 `(7,)`。

```bash
python exercise/lesson01_temperature.py
```

按公式，输出应为 `[8, 4, 0, 0, 0, 4, 8]`。

## 容易混淆的地方

- 这一课的权重和偏置都是手动指定的，还没有学习过程。
- ReLU 把负值变成零，让不同神经元能负责不同区间。
- 只有加权求和、没有非线性激活时，多层这样的变换仍可合并成一次仿射变换。
