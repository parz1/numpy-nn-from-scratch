# 第 4 课：从打车计价到线性层

对应代码：[lesson04_taxi.py](../exercise/lesson04_taxi.py)、[lesson04_train.py](../exercise/lesson04_train.py)。后续实现位置：[nn/layers.py](../nn/layers.py)。

## 本课的问题

前面逐个写神经元。现在把多个神经元排在一起，用一次数组运算计算它们，再理解通用的线性层。

教学用车费规则为：

$$
f(d)=10+2\max(0,d-3)+\max(0,d-10)
$$

3 公里以内 10 元；3 到 10 公里的部分每公里增加 2 元；超过 10 公里的部分每公里总共增加 3 元。

## 三个神经元表示这条规则

`lesson04_taxi.py` 手动设置：

```python
w = np.array([0.0, 1.0, 1.0])
b = np.array([10.0, -3.0, -10.0])
v = np.array([1.0, 2.0, 1.0])

z = D * w + b
a = np.maximum(0, z)
y_hat = a @ v
```

| 数组 | 形状 | 含义 |
| --- | --- | --- |
| D | `(21, 1)` | 21 条记录，每条 1 个输入 |
| w、b | `(3,)` | 3 个神经元各自的权重、偏置 |
| z、a | `(21, 3)` | 每条记录对应 3 个神经元的结果 |
| v | `(3,)` | 合成车费时的 3 个权重 |
| y_hat | `(21,)` | 每条记录的预测车费 |

`D * w` 使用广播：每行的公里数分别乘三个权重。`a @ v` 则对每行加权求和。

例如 15 公里时，激活为 `[10, 12, 5]`，车费是 `10×1 + 12×2 + 5×1 = 39` 元。第一个神经元提供常数项。

## 从手动参数到训练参数

`lesson04_train.py` 将距离和车费都除以 10，再训练 `w,b,v`。当前启用的是 **2 个神经元**，3 个神经元的初值被注释掉了。因此实际 `z`、`a` 是 `(21, 2)`，`dv` 是 `(2,)`；代码部分注释仍写着 3。

训练用的梯度为：

```python
dL_dyhat = 2 * (y_hat - y) / len(y)
dv = a.T @ dL_dyhat
dL_da = dL_dyhat.reshape(-1, 1) * v
dz = dL_da * (z > 0)
dw = (dz * S).sum(axis=0)
db = dz.sum(axis=0)
```

这里已在 `dL_dyhat` 中除以样本数，后面只求和，不再平均。`axis=0` 表示沿样本方向相加，保留每个神经元各自的梯度。

训练脚本打印的 `-b/w*10` 是距离单位下的拐点，仅在对应 `w` 不为零时有意义；`w*v` 是该神经元激活后对车费斜率的贡献。一个区间内的总斜率需要把所有已激活神经元的贡献相加。

当前结尾的 `y_hat` 来自最后一次参数更新之前；若要报告最终更新后模型的预测，应额外前向计算一次。

## 为什么引出线性层

现在每条记录只有公里数一个输入，因此每个神经元只需要一个权重。如果再加入等待时间，每个神经元就需要把两个输入加权相加：

$$
z_{ij}=\sum_{k=1}^{D}X_{ik}W_{kj}+b_j
$$

其中 `i` 是样本编号，`j` 是输出神经元编号，`k` 遍历输入特征。写成矩阵就是：

$$
Z=XW+b
$$

| 数组 | 形状 |
| --- | --- |
| X：N 条样本，每条 D 个输入 | `(N, D)` |
| W：D 个输入到 H 个输出的权重 | `(D, H)` |
| b：每个输出一个偏置 | `(H,)` |
| Z：每条样本的 H 个输出 | `(N, H)` |

单输入时，将原来的 `w` 改成 `(1, H)` 的矩阵，就可以把 `S * w` 表示的计算写成 `S @ W`。

通常称为 `Linear` 的层计算 `X @ W + b`；有偏置时，严格说是仿射变换。ReLU 是后面单独的一步，不包含在线性层中。
