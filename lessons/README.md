后续每课沿用以下结构，随着实际学习补充，不提前把整条路线写成完成记录：

1. 本课想解决的问题。
2. 核心概念与公式，以及它们和代码的对应关系。
3. 数组形状与一个可以手算的例子。
4. 运行方法、实际观察与容易混淆的地方。
5. 自己的理解、疑问与下一步。
